# 🎥 Video Call Application

A full-stack real-time video calling application built using React.js, Node.js, Express.js, Socket.IO, and WebRTC.

## 🚀 Live Demo
https://video-callforntend1.onrender.com/

## ✨ Features

- Real-time Video Calling
- Real-time Audio Calling
- User Authentication
- Secure Peer-to-Peer Communication
- Responsive User Interface
- Fast and Reliable Connection

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Real-Time Communication
- Socket.IO
- WebRTC

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/bittu90060/video-call.git
```

### Install Frontend

```bash
cd frontend
npm install
npm start
```

### Install Backend

```bash
cd backend
npm install
npm start
```
